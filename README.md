# Blood_Gun 恶魔轮盘

> 纯 2D 俯视角恶魔轮盘（Buckshot Roulette 风格）——六孔左轮、生死博弈。
> 支持**单人挑战 AI** 与**局域网双人对战**，纯原生前端 + Node.js，无需任何构建工具。
> 牌桌中央放着一把左轮：**谁的回合谁点击拿起枪**，拿起后才能开枪 / 使用道具。

![Node](https://img.shields.io/badge/Node.js-18%2B-339933) ![2D](https://img.shields.io/badge/Canvas-2D-1f8ac8) ![License](https://img.shields.io/badge/license-MIT-green)

## 游戏简介

- 六孔左轮，每轮随机装入 4~6 发子弹（实弹与空弹数量相差不超过 1 发）
- 双方初始各 2 点生命，对手生命归零即获胜
- **2D 俯视角牌桌**：桌面上有一把左轮，回合开始时枪滑回桌面中央发光，点击即可拿起；拿起后枪握在手中并随鼠标瞄准
- **瞄准射击**：把枪口对准对手或自己再点击开枪；**没有对准目标会打偏**——实弹也不造成伤害，并轮到对手回合
- 每回合可选择：对自己开枪 / 对对手开枪 / 使用 1 个道具（拿起枪后才解锁）

## 游戏模式

### 普通模式

双方按配置获得道具（数量各 0~3，可叠加持有），道具与血量在对战配置中设置。

### 赌局模式（联机专属）

- 道具改为 **4 个卡槽**，抽到的道具按 1→2→3→4 顺序从左到右依次放入，**可抽到相同道具（各占一槽，最多 4 张）**
- 每次换子弹双方各**随机抽取 2 个道具**（卡槽满 4 张则无法抽取）
- 抽取池：看破 / 护盾 / 退蛋 / 双倍威力 / **对决** / **人格面具** / **生死弹**
- 换弹流程：装填动画 → **抽取道具界面**（卡牌翻转展示，与卡槽位置一一对应）

## 道具说明

| 道具 | 效果 |
| --- | --- |
| ◉ 看破 | 查看下一发子弹是实弹还是空弹 |
| ◇ 护盾 | 抵挡下一次实弹伤害 |
| ⏏ 退蛋 | 主动退出发射位的一发子弹（可看到实/空弹），回合继续 |
| ×2 双倍威力 | 下一发实弹伤害翻倍（仅本回合有效，可击穿护盾） |
| ⚔ 对决（赌局） | 进入对决界面：3 秒倒计时（不可操作）→ 随机等待 3~10 秒 → 射击信号出现后最先开枪者获胜；等待期开枪算**提前开火，自己扣 1 血**；胜利造成 1 点伤害（双方都激活双倍威力时最高 4 点）；回合留在发起者、不消耗子弹 |
| ◐ 人格面具（赌局） | 本回合内对自己射击一次，**空弹获得「俄耳甫斯」**；若本回合未对自己射击则卡片失效 |
| ♪ 俄耳甫斯 | 使用后**连续行动两个回合**（本应轮换回合时不轮换） |
| ☯ 生死弹（赌局） | 秘密选择「生/死」（对手不知道），压入一颗子弹并把枪交给对手：对手必须开枪并自行选择射击目标——被射中者**回复 1 点生命**（生，不超过上限）或**损失 1 点生命**（死）；打偏则效果落空；回合回到出牌者 |

### 对战配置

点击"单人模式"或"创建房间"时会弹出配置面板：

- 游戏模式（仅联机创建房间）：普通模式 / 赌局模式
- 看破 / 护盾 / 退蛋 / 双倍威力 的数量（普通模式，各 0~3 个）
- 初始血量（1~5）

配置自动保存（localStorage）；联机模式以房主配置为准。

## 快速开始

### 方式一：便携版（推荐）

1. 从 `dist/` 或 Release 中下载 `恶魔轮盘_BloodGun_便携版.zip`
2. 解压后双击 `start.bat`
3. 浏览器自动打开 `http://localhost:8080`

### 方式二：源码运行

```bash
npm install
npm start
# 打开 http://localhost:8080
```

需要 [Node.js](https://nodejs.org) 18+ 与支持 Canvas 2D 的现代浏览器（Chrome / Edge）。

## 操作说明

2D 俯视角：

| 操作 | 方式 |
| --- | --- |
| 拿起枪 | 回合开始枪在桌面中央发光，**点击枪**拿起（随后解锁开枪与道具） |
| 对对手开枪 | 拿起枪后把枪口对准对手，**点击**开枪 / 键盘 `E` |
| 对自己开枪 | 枪口对准自己，**点击**开枪 / 右键 / 键盘 `S` |
| 打偏 | 没对准目标就开枪：实弹也不造成伤害，并轮到对手回合 |
| 使用道具 | 点击屏幕下方道具栏（拿起枪后可用；赌局模式为卡槽） |
| 对决射击 | 对决界面射击信号出现后**点击屏幕**开火 |
| 对局详情 | 右下角面板，可拖动、可最小化 |

## 局域网联机

1. 房主启动游戏 → 进入"双人联机" → "创建房间"（可先配置模式、道具与血量）
2. 其他玩家（同一局域网）访问 `http://房主IP:8080` → "双人联机" → "加入房间"
3. 房间列表自动刷新，显示房主昵称、模式、道具配置与血量，点击"加入"即可
4. 房主 IP 可在服务器启动窗口查看

> 房间列表每 2.5 秒自动刷新，也可手动点击"刷新"。

## 外观与皮肤

首页「外观 · 皮肤」弹窗可分类选择贴图皮肤。游戏按分类读取 `client/assets/skins/`：`gun`（枪械）/ `avatar`（头像立绘）/ `player`（角色俯视立绘）/ `floor`（地图）/ `table`（牌桌）。每个分类下**每建一个子文件夹 = 一套皮肤**，游戏自动列出：

```
client/assets/skins/
  ├── gun/黑金枪/gun.png        ├── avatar/面具人/avatar-me.png avatar-enemy.png
  ├── player/西装客/player0.png player1.png
  ├── floor/霓虹城/floor.png    └── table/红桌/table.png
```

- 「选择角色」一项同时应用头像与角色贴图；**皮肤只作用于玩家自己**，敌人（AI / 联机对手）默认贴图，联机时对手皮肤由对手自己选择并同步显示
- 单套默认贴图：把同名 PNG 放入 `client/assets/` 根目录，规格见 `client/assets/README.txt`

## 项目结构

```
client/
  index.html    页面结构（首页 / 大厅 / 房间列表 / 对局 HUD / 弹窗 / 对决界面）
  game.js       游戏逻辑（单人 AI、联机客户端、配置、UI 状态、对决/抽卡界面）
  game2d.js     2D 俯视角牌桌渲染（牌桌 / 玩家 / 左轮 / 拿起-射击动画）
  skins.js      皮肤系统（分类贴图皮肤 + 选择持久化 + 联机对手皮肤同步）
  audio.js      程序化机械、枪响、受击、装填与胜负音效
  style.css     全部样式（HUD、弹窗、卡槽、抽卡、对决、房间列表、日志面板）
  assets/       美术贴图目录（PNG 换肤，含 skins/ 分类皮肤包）
server/
  index.js      HTTP 静态服务 + WebSocket 房间/对战逻辑（模式/卡槽/对决权威判定）
start.bat       便携版一键启动脚本
```

## 常见问题

- **提示"连接失败"**：确认服务器已启动（`npm start` 或 `start.bat`），并确认通过 `http://localhost:8080` 访问页面
- **端口被占用**：关闭占用 8080 端口的程序后重试
- **页面显示旧版本**：按 `Ctrl + F5` 强制刷新（资源已带版本号防缓存）
